## 先说结论

只刷 Hot100，不足以稳定通过算法岗笔试。更可靠的能力栈是：

1. **基础保分**：Hot100 Medium 能在 15–20 分钟内写对。
2. **竞赛骨架**：二分答案、二维前缀和、并查集离线、树形/区间 DP、Fenwick、最短路分层、MITM。
3. **ACM 工程**：多测、EOF、大输入、取模、浮点误差、部分分和计时策略。
4. **算法专场支线**：NumPy/JSON 输入、数值稳定、朴素贝叶斯、Viterbi、Attention、异常检测等可运行实现。

公开卷更多是“经典算法换皮或组合”，而不是直接复制 LeetCode。下面把映射分为：

- **原题级**：题意和状态几乎一致。
- **同构**：换了故事、数据或目标表达，但核心算法一致。
- **技术映射**：只能练到其中一个部件，不能把 LC 解答直接提交。

- **A 官方**：公司官网、正式招聘公告或高校转发的公司简章。

### 27 届实习的训练增量

在原 P0/P1 之外，按目标岗位增加：

1. **所有技术/算法岗**：进制与字符串解析、GCD/质因数、复杂规则模拟、固定窗口、连通块编号、函数图。
2. **字节/拼多多/阿里高难场**：生成树构造、树上 DAG DP、线段树、差分约束、二分图最小权匹配。
3. **阿里 AI/腾讯定向 AI Coding**：练“自然语言业务规则 → 明确接口/约束 → 可运行程序”，不要只写提示词说明。
4. **美团/蚂蚁/携程算法专场**：JSON/矩阵输入、稳定 sigmoid/logsumexp、Viterbi、Attention、训练/验证隔离和参数搜索。
5. **网易/华为通用 OJ**：两题或三题的部分分策略；模拟题先定状态、事件顺序和不变量，再编码。

27 届新增高阶专题不代表基础题消失。正确顺序仍是：P0 盲写稳定后，再根据目标公司加入线段树、匹配或 ML 实现。

### 这些场次对训练计划的实际改动

1. **P0 仍然是传统算法**：拼多多四题覆盖模拟、DP、Fenwick 与复杂建模，证明 Hot100 + 竞赛骨架不能被 AI Coding 取代。
2. **新增两个可闭卷模板**：带权区间调度（按结束时间 DP + 二分前驱）和“边按时间到达”的在线 DAG/图 DP（查询旧状态后再更新，避免同一条边污染本轮）。
3. **MITM 从 P1 提到目标京东/阿里/拼多多时的 P0**：数据范围在 30–44 左右且要求精确选 k 个、平衡两组或最接近目标时，先按“半边枚举 + 按选择个数分桶 + 二分”识别。
4. **排序 AI Coding 新增最低线**：会按 query 分组切 train/validation，避免同一 query 泄漏；能实现 `DCG@k`、`IDCG@k`、`NDCG@k`；先做 BM25/字符匹配+数值特征 baseline，再考虑树模型或学习排序。详见[ML / AI Coding 补丁](/blog/ml-ai-coding-patch/)。
5. **Apriori 只学可考骨架**：候选连接、子集剪枝、support 计数、确定性排序；它不应挤占 Fenwick/DSU/DP 的主复习时间。
6. **AI Coding 按 50% 权重计时**：30 分钟内结束选择与 OJ 保分，剩余主时间留给 ML 任务；前 15 分钟必须产出可运行 baseline、合法输出和本地指标。模型只负责可验证的小步修改，每次改动都要重跑数据契约与指标。
7. **同一天也可能多卷**：公开回忆中的不同算法题必须分别建版本，不用“网友 A 的算法题 + 网友 B 的 AI 任务”拼成所谓完整原卷。

## 算法专场的 ML 手写支线

模式识别、数值稳定、JSON 契约、可执行实现和边界测试见[《ML / AI Coding 笔试补丁》](/blog/ml-ai-coding-patch/)。

每个模块都要能独立从 JSON/文本输入运行，不能只写公式：

1. 稳定 `softmax/logsumexp`、交叉熵、标准化；明确 axis 和 shape。
2. 朴素贝叶斯：平滑、先验、对数概率、预测。
3. HMM/Viterbi：对数域 DP、回溯指针、不可达状态。
4. Attention：Q/K/V 维度、缩放、mask、Top-k、归一化。
5. 异常检测/One-Class 思路：训练/验证隔离、阈值选择、固定随机种子。
6. SQL：窗口函数、Top-N、留存、连续登录、分组去重。
7. （2026 新增）CLIP 对比损失：相似度矩阵、双向 softmax CE、减行最大值、双向平均。
8. （2026 新增）IRLS/Newton 逻辑回归与决策树桩：稳定 sigmoid、Hessian 正则、加权 Gini。
9. （2026 新增）KV Cache 淘汰与 RoPE 公式模拟：堆+有序结构、逐对二维旋转、固定小数位输出。
10. （2026 新增）流式 tokenizer 与 sklearn Pipeline：Trie/哈希最长匹配；StratifiedKFold+GridSearchCV，Scaler 只 fit 训练集。

验收不是“看懂”，而是给定一页接口说明后，60–90 分钟内写出可运行程序，并覆盖空输入、单样本、重复值、极端浮点和维度错误。

## 每场模拟的通过策略

1. 前 5 分钟扫完所有题，按预计得分/时间排序，不机械从第 1 题做。
2. 每题先写数据范围推导：`n≤20` 考虑回溯/状压/MITM；`n≤2000` 才考虑 O(n²)；`n≤1e5` 通常需 O(n log n)；`n≤1e6` 偏 O(n)。
3. 20–25 分钟没有正确状态时，提交可验证的暴力/小数据部分分并切题。
4. 最后 15 分钟只查：空集、单元素、重复、负数、1-based/0-based、溢出/取模、递归深度、输出格式。
5. 复盘记录“为什么误判”，不要抄完整答案。次日盲写，7 天后再做一遍。

## 你是否已经达到可投递线

满足下面 5 条再把“刷过”算成“会了”：

- 随机抽 20 道 P0 Medium，17 道能在 20 分钟内独立写对。
- 4 场 120 分钟模拟中，至少 3 场稳定拿下前两题，并在第三题获得有效分数。
- Fenwick、DSU、二分答案、二维前缀和、0/1 背包能从空文件盲写。
- 能把 LeetCode 函数题在 10 分钟内改成多测 ACM 输入输出。
- 目标算法专场时，至少 4 个 ML 模块通过自写边界测试。

这套线比“刷满多少题”更接近真实笔试结果：识别、实现、边界、速度和取舍必须同时过线。
