## 0. 按用途速查

| 你要查什么 | 首选渠道 | 次选 | 可信度提醒 |
|---|---|---|---|
| 批次/截止日/资格 | 公司校招官网 + 官方招聘公众号 | 高校就业网转发 | 只信官方当日页面 |
| 面经/笔试题 | 牛客 | 知乎个人复盘、GitHub 面经仓库 | 一手>聚合；带辅导广告的降级 |
| 部门/组织情报 | 晚点 LatePost、36氪 | 界面、21财经、钛媒体、观察者网 | 媒体报道≠官方确认 |
| 内部口碑/氛围 | 脉脉职言 | 在职校友、牛客"决赛圈"帖 | 情绪偏差大，只当线索 |
| 薪资开奖 | 牛客开奖区/OfferShow | 卡码笔记年度报告、知识星球爆料 | 样本偏差：晒的多是高包 |
| 技术趋势/八股 | 官方技术报告与博客 | GitHub 面试仓库、B站/播客 | 报告为准，八股可能有错答案 |
| 岗位聚合 | 各校就业网、支付宝校招频道、超级简历/AI简历姬等聚合站 | 智联/前程校园频道 | 聚合站日期常滞后，回官网核验 |

## 1. 官方渠道（最高优先级）

- 各公司校招官网与状态：统一维护在[招聘窗口与刷新日志](/blog/recruit-window-refresh-log/)，不在本文重复。
- 官方招聘公众号（投递确认、笔试通知都走它，全部关注并置顶）：字节跳动招聘、腾讯招聘、阿里巴巴集团招聘、蚂蚁集团招聘、美团招聘、百度招聘、京东招聘、拼多多招聘、华为招聘、DeepSeek（官方号发布扩招启事）、月之暗面 Kimi、智谱、MiniMax、小红书招聘、快手招聘、Bilibili 校园招聘。
- 官方候选人反馈渠道示例：字节 candidatefeedback.bytedance.com（进度异常时用）。
- 高校就业网/全国大学生就业服务平台：验证历史批次真伪的可追溯来源（`A-Relay`）。

## 2. 面经与题库

### 2.1 社区平台

| 平台 | 强项 | 用法 | 边界 |
|---|---|---|---|
| 牛客 | 一手面经最全、开奖区、笔试真题库、AI 模拟面试 | 搜"公司+27届/26届+大模型+面经"，按最新排序；置顶关注目标公司讨论区 | 辅导引流帖多（文末带"项目辅导"的降为题目线索）；开奖帖有幸存者偏差 |
| 知乎 | 深度复盘、行业分析 | 搜"公司 大模型 面经 2026"，只取个人完整复盘 | 机构号/培训号只作 `C-Lead` |
| CSDN/博客园/掘金 | 题解型整理、转型记录 | 面试后查具体题的答案时用 | 大量搬运与 JD 扩写模拟题，标注"练习题" |
| 一亩三分地 | 外企/海外岗、部分独角兽流程 | 登录后搜公司版块 | 登录墙；国内岗覆盖弱 |
| 小红书 App | 测评/AI面试经验、女性视角职场信息 | App 内搜"公司+测评/面经"（Web 索引不完整） | 图片贴无法溯源时只作线索 |

## 3. 组织与行业情报（支撑"选组"）

| 来源 | 定位 | 用法 |
|---|---|---|
| 晚点 LatePost | 国内组织架构变动的一手爆料王（Seed 调整、可灵分拆均出自它） | 每两周扫一次；付费墙内容常被 36氪/网易转载 |
| 36氪（含快讯） | 转载+快讯覆盖面最大 | 搜"公司名+组织/调整/裁员" |
| 21财经/界面/每经/钛媒体/观察者网 | 财报、上市、融资、战略解读 | 判断公司层面扩张/收缩 |
| 脉脉 | 员工匿名讨论（职言区） | 搜部门名看氛围与八卦；情绪与利益偏差大，`[传闻]` 级 |
| 公司财报/股东信 | 收入与战略的最硬证据 | 上市公司季报里的 AI 收入表述（如阿里"商业化回报周期"） |

维护动作已并入[部门格局与选组指南](/blog/llm-team-landscape-guide/) §7 的保鲜协议。

## 4. 薪资与 offer 数据

- 牛客开奖区：搜"公司+开奖/薪资+27届"，样本最多但偏高包。
- OfferShow（小程序/App）：结构化薪资样本，看分位数而非最大值。
- 卡码笔记年度薪资报告（[2026 版](https://notes.kamacoder.com/salary/yearly/2026.html)）：按岗位/城市汇总的校招包，含个例出处。
- 脉脉薪资区/知识星球爆料：只作交叉验证。
- 使用原则：谈薪前收集同岗位 ≥5 个当届样本，取中位数做锚；所有网传薪资标 `[传闻]`。

## 6. 检索手册（关键词模板）

```text
# 批次与时间线
公司名 + 2027届 + 校招/秋招/提前批 + 启动/网申/截止
"2027届" + 秋招 + 时间表/汇总 + 8月/9月

# 面经（按新鲜度降序翻）
公司名 + 27届/26届 + 大模型/LLM/多模态 + 面经/一面/二面/手撕
部门名(Seed/LongCat/可灵/混元/通义/百灵/Dots) + 面经/笔试
岗位关键词(后训练/RL/Agent/VLM) + 面经 + 2026

# 组织情报
公司名 + 组织架构/调整/成立/合并/裁员 + 2026
部门名 + 负责人 + 离职/接任/汇报

# 薪资
公司名 + 开奖 + 27届/2026 + 大模型/算法
岗位 + SP/SSP + 总包

# 测评
公司名 + 测评/行测/性格测试/AI面试 + 攻略/几天/挂
```

检索纪律（沿用面经汇总 §8）：帖子日期与事件日期分开记；两个独立一手样本才升级为"多次出现"；带推广的降级；搜不到 ≠ 不存在。

## 7. 每周信息例行（20 分钟 ×2 + 15 分钟 ×1）

- 周一/周四（各 20 分钟，已有协议）：刷[窗口日志](/blog/recruit-window-refresh-log/)官方入口 + 牛客近 7 天面经。
- 周六（新增 15 分钟）：扫晚点/36氪组织类新闻 → 更新[部门情报](/blog/llm-team-landscape-guide/)；扫 OpenRouter/HF 榜单 → 有大发布就加进面试前弹药清单。

## 8. 反诈与边界

- 付费内推、付费"内部题库"、要求向私人邮箱发证件/成绩单的一律拉黑（腾讯、华为官网均有官方反诈提醒）。
- 不加陌生"HR"的私人微信投简历；一切投递走官网或官方公众号内链接。
- 面试后记录题目供个人复盘可以，公开传播带公司保密信息的内容不可以。
