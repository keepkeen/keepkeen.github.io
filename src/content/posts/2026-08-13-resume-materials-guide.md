## 0. 先看结论

1. 简历只有两个读者：**机器（关键词召回）和 10–30 秒的人眼（抓亮点）**。为这两个读者写，不为自己写。
2. 2026 年的行情：RAG/Agent 项目本身不再加分，"讲得清数据、评估和取舍"才加分；论文（即使方向不对口）仍是研究岗最硬的通货。
3. 你的异常检测背景不是包袱——按 §5 的映射表把它翻译成大模型语言，它就是区分度。

## 1. 筛选机制：简历怎么被读

- **第一层 机筛/初筛**：按 JD 关键词与硬条件（学历/毕业时间/专业）召回。对策：简历里自然出现目标 JD 的关键技术词（不是堆砌——每个词都要能被追问）。大模型算法岗高频关键词：SFT、LoRA/QLoRA、DPO/GRPO/PPO、RLHF、RAG、Agent、多模态/VLM、vLLM、DeepSpeed/Megatron、量化、KV Cache、数据清洗/合成、评测。
- **第二层 HR 初看（约 10 秒）**：学校/学历、实习公司名、论文数量、排版整洁度。对策：教育背景与最强亮点放最上面；一眼能找到"硕士、2027 届、方向"。
- **第三层 技术主管细看（约 1–3 分钟）**：项目 bullet 里的数字与技术判断力。对策：每条 bullet 按"做了什么 → 怎么做的（关键决策）→ 数字结果"，全部量化（模板见指南 §8.7）。
- 面试官几乎一定会**照着简历问**：写上去的每一行都是你出给自己的考题。写之前自问三连：数据在哪、baseline 是什么、被追问三层能不能扛住。

## 2. 加分项权重（2026 社区共识与证据）

按对大模型算法岗的边际价值排序：

1. **顶会论文**：方向不对口也有效——2025 届 GNN 背景零大模型项目者凭多篇 A 会拿下腾讯/蚂蚁/美团大模型 SSP 的一手复盘（[牛客](https://www.nowcoder.com/discuss/761014619539320832)）证明"论文证明的是研究能力闭环，不是方向"。投研究岗（Seed/青云/北斗/阿里星专项）论文接近必需。
2. **大厂相关实习**：应用岗最硬的通货；来不及了就用"高质量项目 + 论文"补位（你现在的处境）。百度/字节校招正式员工 50%+ 来自实习转正 `[媒体]`——没有实习意味着你要在笔试面试上更强。
3. **有区分度的项目**：见 §4。
4. **竞赛**（ACM/Kaggle/天池 top）：证明 coding 与建模，边际价值中等。
5. **开源贡献**：给 vLLM/TRL/LLaMA-Factory 这类主流库提有效 PR 才算数；自己开 repo 刷 star 不算。
6. 证书、课程列表：基本无效，删。

## 3. 格式规范与雷点清单

**规范**（硕士应届默认）：

- 一页 PDF；文件名 `姓名-学校-硕士-2027届-岗位方向.pdf`。
- 模块顺序：个人信息（含毕业时间！）→ 教育背景 → 论文/科研 → 项目（2–3 个）→ 实习（如有）→ 技能与荣誉。
- 每个项目 2–4 条 bullet；技术名词英文原文（GRPO 不写"组相对策略优化"）。
- 邮箱用常规服务商；GitHub/主页链接只在内容拿得出手时放。

**雷点**（均有面试官吐槽帖背书，`[汇总]`）：

- 技能栏写"精通"——写"熟悉/掌握"，精通两个字是找拷打。
- 罗列课程名、社团职务、与岗位无关的奖（文体类删除）。
- 项目只写"过程忙碌"不写结果数字；或数字明显编造（"提升 300%"）。
- 同一份简历海投所有方向（后训练岗看到简历第一屏是 RAG demo 会直接降权——用指南 §10.6 的三版重排解决）。
- 占位符/错别字/两栏花哨模板（机筛解析两栏模板易错位，用单栏）。
- 写"了解 Stable Diffusion、CV、NLP、大模型、强化学习、推荐系统"式的全家桶——宽度在算法岗是减分项。

## 4. 项目行情：什么烂大街、什么有区分度（2026-08）

**已经烂大街（只写"跑通"会减分）**：

- LangChain + 向量库 + Prompt 的朴素 RAG 问答 demo（滴滴面试官"你的 RAG 项目太老了"实录：[掘金](https://juejin.cn/post/7663425196099797030)）；
- 纯调 API 的 Agent（无环境、无评测、无失败分析）；
- 跑通 LLaMA-Factory 微调脚本无消融无评估；
- 各培训班同款"医疗/法律问答系统"。

**仍有区分度的做法**（社区面试官口径一致，[牛客](https://www.nowcoder.com/discuss/893051252416737280)）：

- **评估闭环**：自建 golden set（200+ 条、覆盖无答案/跨文档/权限场景），报 Recall@K、MRR、引用准确率、拒答准确率，并写出调优前后的数字变化；
- **工程取舍**：能回答"为什么 RAG 而不是长上下文"（知识实时更新、>1M token 库、多租户、成本），"chunk=512 为什么"，"rerank 带来多少延迟换多少精度"；
- **失败分析**：embedding 相似度高但答案错、离线指标涨线上体验降，这类问题的定位过程；
- **训练证据**：真实跑过 SFT/DPO/GRPO 并能报 GPU-hours、显存峰值、失败实验（对应指南 §8 的项目方案——它的设计在 2026-08 行情下依然是对的，照着做即可）；
- **把 RAG 定位成 Agent 的检索组件**而不是独立产品，展示系统视角。

结论：**不需要换项目，需要换讲法**。你仓库里规划的旗舰项目（3D 缺陷诊断 Agent + evidence verifier + 隔离评测）正好落在"有区分度"一侧，把 §8.7 模板里的方括号用真实数字填上是唯一要紧的事。

## 5. CV/异常检测 → 大模型的简历关键词映射

把原有经验翻译成大模型面试官的语言（每行都必须真实做过，映射不是编造）：

| 你的原有经验 | 简历上的大模型语言 | 面试可展开点 |
|---|---|---|
| 工业缺陷/异常检测 | 长尾分布与弱监督下的可靠性建模；bad case 驱动的迭代 | 数据不平衡、阈值标定、误报代价 → 直通 reward 设计与评测 |
| 点云/3D 视觉 | 多模态感知与空间 grounding；具身智能候选背景 | 美团北斗、拼多多机器人岗、字节具身直接对口 |
| 检测器训练与调参 | 训练稳定性诊断（loss spike、过拟合）、消融设计 | 迁移到 SFT/RL 训练诊断的叙事 |
| CLIP/ViT 使用经验 | VLM 视觉编码器原理与图文对齐 | LLaVA/Qwen-VL 架构必问 |
| 部署/TensorRT/量化（如有） | 推理优化意识（量化、延迟-精度权衡） | KV Cache/vLLM 话题的敲门砖 |
| 评测指标设计（AUROC/PRO 等） | 评测体系设计能力：指标选型、置信区间、泄漏防控 | LLM-as-a-Judge、pass@k 的讨论资本 |

叙事口径直接用指南 §2.2 的 60 秒版本，不要说"CV 不行了所以我转大模型"。

## 6. 投递材料清单（一次备齐，避免流程中断）

- [ ] 简历母版 + 三个定向版本（指南 §10.6），全部 PDF ≤2MB。
- [ ] 证件照电子版（白底+蓝底，正装，≥413×626px）——网申表单常强制要求。
- [ ] 成绩单扫描件（本科+硕士，教务处盖章版）与学籍在线验证报告（学信网，提前办，高峰期出报告慢）。
- [ ] 论文材料：arXiv/DOI 链接、一页版摘要（研究岗附加题）。
- [ ] 奖学金/竞赛证书扫描件（只留与技术相关的）。
- [ ] 身份证正反面扫描（只在 offer 后官方系统上传，任何面试前索要的都是诈骗）。
- [ ] GitHub 整理：置顶 1–2 个真实项目 repo，补 README（运行命令、结果表、失败案例）；删除空仓库。
- [ ] 统一的投递表（公司/岗位ID/简历版本/时间/状态/下次跟进）。

## 7. 版本管理纪律

- 母版是唯一事实源：新数字先进母版，再同步到三个定向版；投出去的每份简历存档（`简历/sent/公司-岗位-日期.pdf`），面试前看的是"当时投的那份"。
- 每轮面试后 30 分钟：把被追问卡壳的 bullet 改写或删除——简历是活文档。
- 项目进展更新（如旗舰项目跑出新数字）触发全版本同步，避免面 A 公司说 F1=0.62、面 B 公司说 0.58。
