## 1. 状态定义

| 状态 | 含义 | 动作 |
|---|---|---|
| `open` | 官方页明确显示当前批次/职位可投 | 当天核验岗位 ID、资格后投递 |
| `open-relay` | 企业公众号/高校转发明确当前批次已开，但官方动态页无法静态核验全部字段 | 先到官方入口核验职位，再投递；不沿用转发页之外的推测 |
| `rolling` | 日常实习/持续招聘，未见统一截止日 | 每周查职位增减 |
| `ended` | 官方明确项目已结束 | 只保留历史记录 |
| `stale` | 旧批次页面仍存在或仍有按钮，但有效性不明 | 登录或询问官方招聘渠道，不据此承诺可投 |
| `verify` | 动态页、转发页或信息冲突 | 人工二次核验后再改状态 |

## 3. 每次投递前的 90 秒核验

- [ ] 公司域名正确，无仿冒站和私人收款。
- [ ] 项目名称、岗位 ID、工作地点已保存。
- [ ] 毕业区间与本人匹配。
- [ ] 岗位是全职、转正实习还是日常实习。
- [ ] 截止时间来自官方页或官方 HR，而不是社交平台海报。
- [ ] 简历版本与岗位方向匹配：后训练 / Agent / 多模态。
- [ ] 没有向非官方渠道提交身份证、证件原件、账号密码或未公开项目数据。
- [ ] 投递表记录 `applied_at / source / referral / status / next_followup`。
