# 11. Deep Residual Learning：把“学一个函数”改写成“修正恒等映射”

> **论文：** He et al.，CVPR 2016　**出处状态：** 27 项保留清单　**原文：** [arXiv:1512.03385](https://arxiv.org/abs/1512.03385)

## 一句话定位

ResNet 的决定性一步不是单纯加深网络，而是把一个层组写成 `y = x + F(x)`。恒等支路让信号和梯度拥有一条无参数的直达路径，残差支路只需学习相对输入的修正，于是“更深至少不应更差”从一个存在性论证变成了优化器更容易找到的参数化。

## 为什么会被推荐

**已知**：它出现在保留清单，而且 Ilya 是 AlexNet 作者之一；没有可信材料记录他对本篇的逐篇评语。**合理推断**：ResNet 展示了深度学习里极重要的一类进步——模型表达能力没有发生神秘变化，改变参数化和信息路径就能显著改变可优化性。它还是后来 Transformer 残差流、超深语言模型和许多数值迭代网络的共同祖先。

## 问题、核心贡献与理论

论文先区分了两个问题。梯度消失/爆炸可由初始化和 BatchNorm 缓解；但即使网络能收敛，34 层 plain net 的**训练误差**仍高于 18 层，这不是过拟合，而是 degradation：优化器没有找到本来必然存在的“不差于浅网”的解。

若目标映射为 `H(x)`，残差块改学 `F(x)=H(x)-x`：

`y = F(x,{W_i}) + x`。

若维度变化，则用投影 `y=F(x)+W_s x`；维度不变时坚持无参数 identity shortcut。论文的论证不是“残差形式表达能力更强”——两种形式理论上都能逼近目标——而是当最优映射接近恒等时，把残差推向零比用多层非线性精确拟合恒等更容易。这可理解为一种架构级预条件（preconditioning）。

反向看得更清楚。沿若干理想恒等块，输出含有输入的加法项，损失对早期表示的梯度也含一条不必连续乘权重矩阵的项。它不能保证梯度永不衰减，也不是完整收敛定理，但说明 shortcut 为什么能重塑优化地形和有效路径长度。

## 怎么实现、怎么理解

原始 ImageNet 基本块使用 `conv → BN → ReLU → conv → BN → 加法 → ReLU`；50/101/152 层使用 `1×1 → 3×3 → 1×1` bottleneck 降低计算。只有空间尺寸或通道数变化时，shortcut 才需要 stride 或 `1×1` 投影。

最实用的理解是“先复制，再写增量”：若某一块暂时没学到有用变换，它至少可以接近恒等；每个块像一次状态更新 `x_{t+1}=x_t+F_t(x_t)`。这也解释了它与 Euler 离散化、boosting 和多重网格残差修正的结构相似，但论文没有声称神经 ODE 理论是其原始推导。

[`src/ilya30/vision.py`](../../src/ilya30/vision.py) 实现无框架残差块示例，并用零残差、维度匹配和数值梯度检查恒等路径；完整训练应直接使用 [torchvision ResNet](https://pytorch.org/vision/stable/models/resnet.html)，而不是重造数据管线。

## 同期相关工作与后续解释

[VGG](https://arxiv.org/abs/1409.1556) 证明规则堆叠小卷积核能从深度获益，却在继续加深时遇到训练障碍；[Highway Networks](https://arxiv.org/abs/1505.00387) 用可学习门控制变换与携带支路，表达更灵活但门会关闭且增加参数。ResNet 的强点恰是 shortcut 永远开放。

后续 [Identity Mappings](16-identity-mappings-resnet.md) 把激活也移到残差支路前，使加法后的主干更接近真正恒等。[ResNets Behave Like Ensembles](https://arxiv.org/abs/1605.06431) 从大量不同长度路径解释鲁棒性；[Neural ODE](https://arxiv.org/abs/1806.07366) 把状态增量推到连续深度；[Fixup](https://arxiv.org/abs/1901.09321) 则说明合适初始化可在无归一化时训练很深的残差网。这些是互补视角，不应冒充原论文已经证明的理论。

## 证据、优点与局限

ResNet-152 单模型在 ImageNet 验证集达到 4.49% top-5 error，6 模型集成测试误差 3.57%，并赢得 ILSVRC 2015 分类赛；它的 11.3B FLOPs 仍低于 VGG-19 的 19.6B。CIFAR 上能优化 100/1000 层网络，但 1001 层测试表现受数据少和过拟合影响，说明“可训练”不等于“越深越好”。

优点是参数/计算增量极小、组件通用、梯度路径短，并允许深度真正转化为精度。局限是：投影 shortcut 会削弱纯恒等性质；极深模型仍依赖初始化、归一化和残差尺度；加法要求形状相容；残差连接不能解决数据、目标函数或算力瓶颈。现代模型还会出现表示坍缩、过平滑或深层贡献很小，不能只靠堆块。

## 跨领域应用

语音、图网络、扩散模型 U-Net、控制、PDE 求解器和 Transformer 都可把复杂变换写成状态增量。迁移时要保留的不是 `3×3` 卷积，而是三个条件：稳定的基准路径、只学习必要修正、在形状变化处明确投影。
