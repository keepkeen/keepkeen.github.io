# 17. Relation Networks：把“比较对象”写进网络的计算图

> **论文：** Santoro et al.，NeurIPS 2017　**出处状态：** 27 项保留清单　**原文：** [arXiv:1706.01427](https://arxiv.org/abs/1706.01427)

## 一句话定位

Relation Network（RN）枚举对象对，用同一个 `g_θ` 计算每对关系，求和后由 `f_φ` 回答问题：`RN(O)=f_φ(Σ_{i,j}g_θ(o_i,o_j))`。它把关系推理所需的参数共享、全对比较和顺序不变性直接放进架构，而不是指望普通 MLP/CNN 从数据中偶然学会。

## 为什么会被推荐

**已知**：它在保留清单，没有逐篇推荐语。**合理推断**：RN 是归纳偏置的干净案例：能力不仅取决于网络大小，也取决于计算被如何分解。它与 MPNN 的稀疏边消息、Transformer 的加权全连接边和 Relational RNN 的跨时间记忆关系互相照亮。

## 核心思想与理论性质

输入对象集合 `O={o_1,…,o_n}`。`g_θ` 接受有序对象对；在问答任务中还拼接问题向量 `q`：`g_θ(o_i,o_j,q)`。同一函数用于所有 `n²` 对，因此模型只学一种通用关系计算器。对 pair outputs 求和后，`f_φ` 推断答案。

求和使最终结果对对象枚举顺序不变。若交换 `(i,j)` 会改变关系，保留有序对；若已知图结构，可只计算合法边。这里“object”不要求有人工标签：视觉任务把 CNN 特征图的每个 cell 加坐标当作对象，端到端梯度可迫使 CNN 形成适合 RN 的隐式对象表示。

这种强偏置把参数效率换成计算：普通 MLP 一次处理拼接输入，但须隐式学习各位置的比较规则；RN 共享一次规则却执行 `O(n²)` 个 pair MLP。它能表示二元关系的聚合，但多步组合推理可能需要堆叠、迭代或显式程序。

## 如何实现和理解

把一组球想成表：`g` 为每两行生成“左于、远于、同色”等未命名特征，sum 制成整场景的关系摘要，`f` 根据问题读出答案。问题向量必须进入 `g`，因为“离红球最远”与“和红球同材质”需要不同的比较。

[`src/ilya30/graphs.py`](../../src/ilya30/graphs.py) 实现全对 `relation_network`，支持 question conditioning 和可选 edge list。测试验证对象随机重排不改变聚合、反转一条边会改变非对称关系，并显示 pair 数按 `n²` 增长。

## 当时其他路线

[Interaction Networks](https://arxiv.org/abs/1612.00222) 在已知物体图上计算边效应再更新节点，适合动力学；[MPNN](13-neural-message-passing.md) 以邻接关系和多步传播统一图模型；[Memory Networks](https://arxiv.org/abs/1410.3916) 用查询读事实；神经模块网络把问题程序拆成可组合模块，但常需要程序监督。RN 的特色是单模块、无需显式关系标签或问题程序。

后续 [Deep Sets](https://arxiv.org/abs/1703.06114) 给出集合不变函数的通用形式；[Non-local Networks](https://arxiv.org/abs/1711.07971) 和 self-attention 用数据相关权重聚合 pair 信息，避免先把每条边都映射成大向量；Slot Attention/对象中心模型试图更可靠地形成对象。图 Transformer 则同时加入边结构和全局注意。

## 证据、优点和局限

CNN+LSTM+RN 在 CLEVR pixels 上达到 95.5% accuracy，高于论文引用的人类 92.6% 和先前 stacked-attention 68.5%；“超人”只指这一合成数据集指标，不等同一般视觉推理超越人类。state description 版本为 96.4%；联合训练 bAbI 通过 18/20；物理系统上能恢复对象连接关系。

优点是结构极简、端到端、对象顺序不变、关系函数共享且数据效率较好。局限是全对计算/内存 `O(n²)`；CNN cell 不一定对应真实对象；sum 可能丢失计数或高阶结构的细节；CLEVR/bAbI 规则化且分布内，难以代表开放世界组合泛化；所谓 relation embedding 未必有可解释语义。

## 跨领域应用

物理粒子、分子、场景对象、多智能体、表格行、事件和候选方案比较都可套用。对象多时应先用空间邻域、检索、稀疏图或 top-k attention 筛边；若目标要求多跳因果链，则要迭代 RN 或保留中间节点状态，而不是一次 sum 后期待全部完成。
