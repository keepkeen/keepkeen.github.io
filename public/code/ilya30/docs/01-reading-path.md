# 依赖式阅读路线

原流传顺序更像资料夹顺序，不像课程。下面的路线让概念按依赖出现。

## 第一阶段：训练神经网络的基本语言

先读 CS231n 的线性分类、反向传播、优化、卷积部分，再读 AlexNet。前者解释工具，后者展示数据、GPU、ReLU、正则化和卷积如何共同跨过工程临界点。随后读 ResNet 和 Identity Mappings，理解深度增加为什么会出现优化退化，以及恒等路径如何改变信号传播。

建议顺序：27 → 08 → 11 → 16 → 12。

## 第二阶段：序列、记忆与对齐

从字符 RNN 建立循环计算直觉，再用 LSTM 理解门控记忆和梯度路径。RNN Regularization 解释循环结构中 dropout 应放在哪里。Bahdanau attention 先解决固定向量瓶颈，Pointer Networks 再把注意力分布直接解释为输出；最后进入 Transformer 和 Annotated Transformer。

建议顺序：03 → 04 → 05 → 15 → 07 → 14 → 01。

## 第三阶段：集合、关系、图和外部记忆

Set2Set 处理无序输入，Relation Networks 显式枚举对象关系，MPNN 把局部消息传递统一成图计算。Neural Turing Machines 把参数记忆扩展成可微外部存储，Relational RNNs 再让记忆槽之间进行注意力交互。

建议顺序：09 → 17 → 13 → 21 → 19。

## 第四阶段：生成建模、语音和大模型系统

Variational Lossy Autoencoder 讨论潜变量与强解码器如何分工。Deep Speech 2 展示端到端目标、数据规模与系统工程的联合作用。GPipe 处理单设备放不下模型时的流水并行；Scaling Laws 把模型、数据和算力之间的经验关系写成可预测曲线。

建议顺序：18 → 22 → 10 → 23。

## 第五阶段：压缩、复杂性与通用智能

先学 Kolmogorov 复杂度的定义和不可计算性，再读 MDL 教程与 Hinton–van Camp 的权重编码。Complexodynamics 和 Coffee Automaton 把“随机”“有结构”“处于中间复杂度”区分开。最后读 Machine Super Intelligence，把 Solomonoff 归纳、AIXI、智能度量与可计算性边界放到同一框架中。

建议顺序：26 → 24 → 06 → 02 → 20 → 25。

## 第六阶段：缺失元学习部分的三条路线

外部记忆路线把新标签—样本关系快速写入记忆；原型网络把每类支持样本压成一个中心；MAML 学一个能被少数梯度步骤快速修改的初始化。三者分别体现“存进去”“量距离”“学会怎么更新”。

建议顺序：28 → 29 → 30。

## 一条最短的 10 项主线

若只想先建立现代深度学习骨架，可按：27 → 08 → 11 → 04 → 15 → 14 → 01 → 13 → 23 → 24。它覆盖反向传播与卷积、规模化视觉、残差路径、门控序列、注意力、Transformer、图表示、规模规律和归纳偏置。
